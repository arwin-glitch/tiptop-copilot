## 3. Non-negotiable invariants — do not regress these

These are the product's spine. Several tests exist specifically to protect them.

1. **Unknown stays unknown.** A field the sources do not state is `null`. No
   defaults, no sentinels, no inference-as-value. Extraction refuses to write a
   field it cannot attach a real citation to.
2. **Unscored ≠ zero.** A scorecard category with no evidence is
   `status: 'unscored'` and is excluded from the normalised score. It lowers
   completeness and confidence only. `computeScorecard` normalises over
   *attempted* weight.
3. **The model proposes; the code decides.** `deriveRecommendation()` applies
   Nick's configured thresholds. The model may argue *down* from the arithmetic,
   never up.
4. **A hard red flag caps, it does not veto.** It caps the label at MONITOR
   without touching the underlying score, so resolving it restores the original
   recommendation with no re-analysis.
5. **The AI cannot mark a deal invested.** `INVESTED` is absent from the output
   enum; `deal_decisions.actor` has a DB-level `check (actor = 'human')`.
6. **No send capability.** No `gmail.send` scope is requested anywhere.
   `generated_drafts.sent` has `check (sent = false)`. There is deliberately no
   `sendDraft()` function.
7. **Untrusted content is fenced, never obeyed.** Email/attachment/document/web
   text goes through `fenceUntrusted()` with `UNTRUSTED_CONTENT_RULE`. Detection
   *annotates*, never hides — a false positive must not make an email invisible.
8. **No fabricated citations.** `CitationRegistry.resolve()` drops unknown
   source ids and the caller writes a `security.citation_rejected` audit event.
9. **No introductions to people who do not exist.** Portfolio suggestions are
   filtered against the org's own `network_contacts` ids.
10. **Corrections are additive.** `deal_facts` is append-only with
    `superseded_by`.
11. **No `dangerouslySetInnerHTML`** except the one audited theme-bootstrap
    script in `layout.tsx` (has an `eslint-disable-next-line no-restricted-syntax`
    with a written justification). An ESLint rule enforces this.
12. **Sync is idempotent by construction** — natural-key upserts plus
    deterministic `idempotency_key` on `sync_runs`.
13. **No invented investment parameters.** Check size, ownership, geography and
    required traction ship **empty** and are excluded from scoring until set.

## 4. Gotchas already hit (don't rediscover these)

- `DemoStore` casts need `as unknown as Row<T>` — the `TableMap` union collapses
  to `never` otherwise.
- Vitest 4 has no `poolOptions`; use `fileParallelism: false`.
- Zod 4: use `z.toJSONSchema()`; `toModelJsonSchema()` in `src/lib/ai/schemas.ts`
  inlines `$ref`s and strips keywords Anthropic's structured outputs reject.
- `claude-haiku-4-5` (the fast tier) does **not** support adaptive thinking or
  `effort`. `AnthropicProvider` gates both behind `supportsAdaptiveThinking()` /
  `supportsEffort()`. Sending them to Haiku is a 400.
- Model ids come from env only: `AI_MODEL_FAST` (default `claude-haiku-4-5`),
  `AI_MODEL_DEEP` (default `claude-opus-5`). Never hard-code at a call site.
- The scaffold's `LayoutProps<"/">` type doesn't exist without `next typegen` —
  `layout.tsx` now uses an explicit prop type.
- Icons are generated by `node scripts/generate-icons.mjs` (hand-rolled PNG
  encoder — no native image dep). Already run; output verified visually.
